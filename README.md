## MERBL-RUN
Merbl is an open-source, customizable, 3D-printed marble run designed in Onshape. It helps beginners learn CAD by creating modular tracks, sturdy bases, and fun obstacles like funnels, plinkos, and swirls.

- Learned the basics of 3D CAD design using Onshape.

- Explored how gravity, momentum, and friction affect marble movement.
- Learned to design parts with 3D printing and assembly in mind.
